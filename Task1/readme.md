# Задание 1: Разработка проверочного листа по безопасности данных

В данном задании необходимо создать проверочный лист по безопасности данных, так как это является ключевой проблемой компании и самым уязвимым местом в её системе.

## Этапы выполнения задания

1. **Анализ исходных материалов:**
   - Изучите диаграмму и описание системы PropDevelopment.

2. **Классификация данных:**
   - Разделите данные компании согласно стандартам ISO/IEC 27001 и ISO/IEC 27002.
   - Классифицируйте данные по четырём категориям:
     - Публичные данные
     - Внутренние данные
     - Конфиденциальные данные
     - Секретные данные

3. **Анализ рисков:**
   - Определите риски для каждой категории данных. Возможные риски:
     - Утечка данных
     - Потеря данных
     - Искажение данных
     - Некачественные данные
     - Обесценивание данных
   - Объясните, почему тот или иной риск актуален для соответствующей категории.

4. **Оценка рисков:**
   - Присвойте оценку каждому риску по шкале: *незначительный*, *значительный*, *критический*.

5. **Визуализация результатов:**
   - Создайте mindmap с использованием draw.io.
   - В центре разместите блок «Безопасность данных».
   - От центра проведите стрелки к категориям данных, где для каждой категории укажите:
     - Тип данных, входящих в данную категорию.
     - Соответствующий риск с оценкой.
     - Обоснование выбранной оценки.

6. **Загрузка результата:**
   - Готовую mindmap загрузите в директорию `Task1` вашего репозитория.
