# Анализ системы и выбор разделов для проверочного листа безопасности

## Идентификация систем и оценка их работы с точки зрения безопасности

### Сервисы для продаж
- **Компоненты:** Витрина продаж, client-tour-app, client-mart-app, client-crm-app, client-mart-estate-app.
- **Особенности:** Каждое приложение (за исключением витрины) использует отдельную базу данных.
- **Основные риски:** утечка клиентских данных, несанкционированный доступ к информации о недвижимости, уязвимости в API для онлайн-сделок.

### Сервисы ЖКУ
- **Компоненты:** Витрина, tenant-core-app, CRM для собственников.
- **Основные риски:** утечка персональных данных собственников, несанкционированный доступ к информации о ЖКУ, уязвимости в API для оплаты услуг.

### Финансовые сервисы
- **Компоненты:** Accountant-service-1 и служба каталогов.
- **Основные риски:** утечка финансовых данных, несанкционированный доступ к бухгалтерским системам.

### Клиентские сервисы
- **Компоненты:** Монолитное приложение для подбора и бронирования недвижимости.
- **Основные риски:** утечка данных клиентов, несанкционированный доступ к информации о бронированиях, уязвимости в интеграции с государственными органами.

### Инфраструктура
- **Компоненты:** Приватное облако, ЦОД, гибридное развертывание.
- **Основные риски:** недостаточная защита данных в гибридной среде, уязвимости в межсетевом экране, неадекватное резервное копирование.

### API партнёров
- **Компоненты:** Интеграция с системами управляющих компаний.
- **Основные риски:** утечка персональных данных через API, несанкционированный доступ к данным через API, отсутствие единых политик безопасности.

## Выбор разделов для проверочного листа безопасности

### Основные проблемы компании PropDevelopment
- **Нарушенный контроль данных:**
  - Несколько независимых точек регистрации клиентов.
  - Отсутствие централизованного контроля за передачей данных между IT-продуктами.
  - Недостаточные ограничения доступа к данным со стороны систем обработки.
- **Проблемы с API партнёров:**
  - Отсутствие унифицированных политик безопасности при интеграции с API управляющих компаний.
  - Уязвимости в API-контрактах, позволяющие несанкционированный доступ к персональным данным.

### Приоритеты компании
- Усиление контроля над данными.
- Обеспечение безопасности API.
- Улучшение управления доступом.
- Защита данных и предотвращение утечек.

## Разделы проверочного листа и их обоснование

### Управление доступом
- **Значимость:** Нарушенный контроль над данными требует, чтобы доступ предоставлялся только авторизованным пользователям и системам.
- **Проверка:** Права доступа к данным, контроль над API партнёров и ролевая модель доступа.

### Защита данных
- **Значимость:** Утечка данных может привести к потере доверия клиентов и собственников, а также вызвать юридические последствия.
- **Проверка:** Шифрование данных в хранилищах и при передаче, а также наличие механизмов предотвращения утечек.

### Безопасность API
- **Значимость:** Проблемы с API партнёров критичны, поскольку могут вызвать утечку персональных данных и несанкционированный доступ.
- **Проверка:** Анализ API-контрактов на предмет уязвимостей, контроль за передаваемыми данными и соблюдение политик безопасности при интеграции.
